================================================
PORTFOLIO WEBSITE - KORTE INSTALLATIE-INSTRUCTIE
================================================

STAP 1 — Database importeren
-----------------------------
1. Open phpMyAdmin (bijv. http://localhost/phpmyadmin)
2. Klik bovenin op "Importeren"
3. Kies het bestand: database.sql
4. Klik op "Uitvoeren"
   -> Je hebt nu een database "portfolio_db" met projecten en 1 testgebruiker.

STAP 2 — Databaseverbinding instellen
-------------------------------------
Open: database.php

Pas eventueel de username / password aan, afhankelijk van jouw lokale setup:
- MAMP:    username = 'root'      password = 'root'
- XAMPP:   username = 'root'      password = ''  (leeg)
- Docker:  wat jij in je docker-compose hebt ingesteld

STAP 3 — Project starten
------------------------
Zet de map 'portfolio' in je webserver-map (htdocs / sites / docroot).
Open daarna: http://localhost/portfolio/

(Of welk pad jij ook gebruikt op jouw lokale server.)
